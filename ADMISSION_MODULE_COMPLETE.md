## File Upload Implementation

### Photo Upload with Preview:
```javascript
const handleFileChange = (e, fieldName) => {
  const file = e.target.files[0]
  if (file) {
    // Validate file size (max 5MB)
    if (file.size > 5 * 1024 * 1024) {
      Swal.error('Error!', 'File size should not exceed 5MB')
      return
    }

    // Validate file type for photos
    if (fieldName.includes('photo')) {
      if (!file.type.startsWith('image/')) {
        Swal.error('Error!', 'Please upload a valid image file')
        return
      }
    }

    setFormData(prev => ({ ...prev, [fieldName]: file }))

    // Create preview for photos
    if (fieldName.includes('photo')) {
      const reader = new FileReader()
      reader.onloadend = () => {
        setPreviews(prev => ({ ...prev, [fieldName]: reader.result }))
      }
      reader.readAsDataURL(file)
    }
  }
}
```

### FormData Submission:
```javascript
const submitData = new FormData()

// Append all text fields
Object.keys(formData).forEach(key => {
  if (formData[key] !== null && formData[key] !== '' && !(formData[key] instanceof File)) {
    submitData.append(key, formData[key])
  }
})

// Append files
if (formData.student_photo) submitData.append('student_photo', formData.student_photo)
if (formData.father_photo) submitData.append('father_photo', formData.father_photo)
if (formData.mother_photo) submitData.append('mother_photo', formData.mother_photo)
if (formData.birth_certificate) submitData.append('birth_certificate', formData.birth_certificate)
if (formData.aadhar_card_front) submitData.append('aadhar_card_front', formData.aadhar_card_front)
if (formData.aadhar_card_back) submitData.append('aadhar_card_back', formData.aadhar_card_back)

// Send with proper headers
const response = await fetch('http://127.0.0.1:8000/api/admin/student-admissions/store_studnt_admssn', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`
    // NO Content-Type header - browser sets it automatically with boundary
  },
  body: submitData
})
```

## Usage Guide

### Adding New Admission:
1. Go to **Students → Student Admission**
2. Fill all required fields (marked with *)
3. Upload student photo (click upload box)
4. Upload father and mother photos
5. Upload documents (optional but recommended)
6. Click "Submit Admission Form"
7. Success alert will show with admission number
8. Form will reset automatically

### Viewing All Admissions:
1. Go to **Students → All Admissions**
2. See list of all admissions with admission numbers
3. Use search to filter by name, admission no, class, etc.
4. Click eye icon to view complete details
5. Click delete icon to remove admission (with confirmation)

### Admission Number:
- **Auto-generated** by backend
- **Read-only** field
- Format: 0001, 0002, 0003, etc.
- Displayed in All Admissions list
- Cannot be edited by user
