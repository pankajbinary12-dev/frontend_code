# 🎓 School Management Dashboard

A beautiful and modern school management dashboard built with React and Vite.

## ✨ Features

- 📊 Interactive Dashboard with real-time data
- 👥 Student & Staff Management
- 📅 Attendance Tracking
- 🎂 Birthday Notifications
- 📚 Academic Management
- 💬 Messaging System
- 📢 Notice Board
- 🎨 Beautiful Gradient UI
- 📱 Fully Responsive Design

## 🚀 Installation

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## 🛠️ Tech Stack

- React 18
- Vite
- Lucide React (Icons)
- CSS3 with Gradients
